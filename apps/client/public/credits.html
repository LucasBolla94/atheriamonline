A little world, made for you.

Atheriam is an original contemporary social city.

The resident animations, city buildings, public furniture and welcome illustration were created for Atheriam using OpenAI's image generation tool. They are original generated assets, with game-specific frame alignment and palette variants. Terrain textures and interface pictograms are original project code.

The welcome illustration sets the atmosphere; it is not a gameplay screenshot. No artwork from Habbo, Tibia or other commercial games is used. System fonts are provided by your device.

The browser game is built with Phaser, React and Vite. Its servers use Fastify, PostgreSQL and Redis.
